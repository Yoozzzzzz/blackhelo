# 黑洞吞噬城市 · 可运行原型

## 环境
- Node.js 20.19+（建议使用当前 LTS）
- npm

## 启动
```bash
npm install
npm run dev
```
打开终端输出的本地地址（通常是 http://localhost:5173）。

## 当前版本
- Three.js 3D 城市网格、道路、简化建筑、汽车和树木
- 鼠标移动控制黑洞
- 吞噬较小物体、得分和黑洞成长
- 90 秒倒计时、结束界面和重开
- 建筑使用底部向上的程序化 Shader 消融、噪声边缘和同步阴影材质
- 黑洞包含紫色发光边缘、旋转吸积盘、点光源和环形粒子
- 物体被吸入时平滑靠近目标、旋转、缩小并下沉，移除时释放几何体和材质
- Vite 本地开发与生产构建

## 已知限制
当前仍使用程序化低多边形模型，没有音效、移动端触控、后处理体积光或真实资产管线；这些不属于本阶段范围。

## 构建
```bash
npm run build
npm run preview
```
构建产物位于 `dist/`，可部署到任意静态网站托管服务。
